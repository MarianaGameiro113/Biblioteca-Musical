# 🎵 Sistema Musical

## 📌 Sobre o Projeto

O **Sistema Musical** é um projeto desenvolvido para organizar e gerenciar artistas e músicas em uma única plataforma. O sistema possui uma interface simples e intuitiva, permitindo navegar entre as telas de cadastro de artistas, cadastro de músicas e biblioteca musical.

O projeto foi desenvolvido utilizando HTML5 e CSS3, com foco na organização das informações, na facilidade de uso e na criação de uma interface responsiva.

## 🚀 Funcionalidades

O sistema conta com as seguintes telas e funcionalidades visuais:

- **Login:** Tela de acesso ao sistema por meio de usuário e senha.
- **Menu Principal:** Página inicial com acesso às principais funcionalidades.
- **Cadastro de Artistas:** Formulário para inserir nome, gênero musical, país e foto do artista.
- **Cadastro de Músicas:** Formulário para adicionar título, artista, álbum, gênero, link do YouTube, capa e letra da música.
- **Biblioteca Musical:** Listagem das músicas cadastradas, com opções de busca e filtros por artista e gênero.
- **Gerenciamento:** Interface com opções de editar e excluir registros.

## 🛠️ Tecnologias Utilizadas

- HTML5 — Estruturação das páginas.
- CSS3 — Estilização e organização visual.
- Flexbox e Grid — Organização dos elementos da interface.
- Media Queries — Adaptação do layout para diferentes tamanhos de tela.

## 🎨 Interface

O sistema utiliza uma identidade visual com tons de azul, cinza e branco, proporcionando uma aparência organizada e agradável.

O arquivo `styles.css` centraliza a estilização de todas as páginas, mantendo um padrão visual entre os formulários, botões, tabelas, menus e demais componentes.
